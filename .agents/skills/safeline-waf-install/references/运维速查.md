# 雷池运维速查

## 目录

| 路径 | 说明 |
|---|---|
| `/opt/safeline` | 默认安装目录（含 compose 文件、证书、配置） |
| `/opt/safeline/compose.yaml` | 编排文件，可用 `docker compose` 操作 |
| `/opt/safeline/resources` | 静态资源、证书 |
| `/opt/safeline/logs` | 本地日志 |
| `/opt/safeline/data` | 数据卷 |

## 服务启停

```bash
cd /opt/safeline

# 启动
bash compose.yaml up -d

# 停止
bash compose.yaml down

# 重启
bash compose.yaml restart

# 查看状态
docker ps --filter "name=safeline"
```

## 常用运维命令

```bash
# 实时日志
docker logs -f safeline-mgt
docker logs -f safeline-detect

# 进入容器
docker exec -it safeline-mgt sh

# 重置管理员密码
docker exec safeline-mgt resetadmin

# 资源占用
docker stats --no-stream $(docker ps -q --filter "name=safeline")
```

## 版本升级

在线升级（官方提供）：

```bash
bash -c "$(curl -fsSLk https://waf-ce.chaitin.cn/release/latest/manager.sh)" -- upgrade
```

> 升级过程服务会重启，流量短暂中断。

LTS 版本升级、离线升级见官方文档「版本升级」章节。

## 端口

| 端口 | 用途 |
|---|---|
| 9443 | 控制台（默认） |
| 80 / 443 | 业务流量（反代接入的站点走这里） |

## 反向代理接入

在雷池控制台 →「添加应用」中配置：
- 监听端口（通常 80/443）
- 域名
- 上游地址（后端真实服务 IP:端口）
- 上游健康检查（可选）

配置完成后把域名的 DNS 解析指向雷池服务器，并在上游服务器放行来自雷池 IP 的回源流量。
