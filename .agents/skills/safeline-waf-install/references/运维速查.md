# 雷池运维速查

## 安装目录

| 路径 | 说明 |
|---|---|
| `/data/safeline` | **官方默认安装目录**（安装时询问，留空即用此路径） |
| `/data/safeline/docker-compose.yaml` | 编排文件 |
| `/data/safeline/resources` | 静态资源、证书 |
| `/data/safeline/logs` | 本地日志 |

## 服务启停

```bash
cd /data/safeline

# 启动
docker compose -f /data/safeline/docker-compose.yaml up -d

# 停止
docker compose -f /data/safeline/docker-compose.yaml down

# 重启
docker compose -f /data/safeline/docker-compose.yaml restart

# 查看状态
docker ps --filter "name=safeline"
```

## 端口与网络排查

雷池各容器多用 `host` 网络模式，此时 `docker port <容器>` 返回空属正常，**不能据此判断"没有对外端口"**。
确认实际监听请用：

```bash
ss -lntp | grep -E '9443|65443'
docker inspect safeline-tengine --format '{{.HostConfig.NetworkMode}} {{json .NetworkSettings.Ports}}'
```

- `9443` 由 `docker-proxy` 监听，是控制台端口。
- `65443` 由容器内的 nginx 进程监听，是 tengine 的 HTTP 入口。

## 常用运维命令

```bash
# 实时日志
docker logs -f safeline-mgt
docker logs -f safeline-detect

# 进入容器
docker exec -it safeline-mgt sh

# 重置管理员密码
docker exec safeline-mgt resetadmin

# 资源占用
docker stats --no-stream $(docker ps -q --filter "name=safeline")
```

## 版本升级

在线升级（官方提供）：

```bash
bash -c "$(curl -fsSLk https://waf-ce.chaitin.cn/release/latest/manager.sh)" --upgrade
```

> 升级过程服务会重启，流量短暂中断。

LTS 版本升级、离线升级见官方文档「版本升级」章节。

## 端口

| 端口 | 用途 |
|---|---|
| 9443 | 控制台（默认） |
| 80 / 443 | 业务流量（反代接入的站点走这里） |

## 反向代理接入

在雷池控制台 →「添加应用」中配置：
- 监听端口（通常 80/443）
- 域名
- 上游地址（后端真实服务 IP:端口）
- 上游健康检查（可选）

配置完成后把域名的 DNS 解析指向雷池服务器，并在上游服务器放行来自雷池 IP 的回源流量。
