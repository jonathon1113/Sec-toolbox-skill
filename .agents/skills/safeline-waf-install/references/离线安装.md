# 雷池离线安装

当目标主机无法访问互联网时使用。

## 官方离线安装包

雷池官方提供离线安装包下载：
<https://help.waf-ce.chaitin.cn/node/01973fc6-e046-7489-bcd7-7b1554393895>（离线安装）

步骤概述：

1. 在与目标机**同架构**的联网机器上下载离线包；
2. 拷贝到目标机；
3. 用 `docker load` 导入镜像；
4. 用随包的 compose 文件启动。

具体命令请以官方文档当前版本为准。

## 依赖镜像

雷池 CE 主要镜像：

```
chaitin/safeline-mgt
chaitin/safeline-detect
chaitin/safeline-nginx
chaitin/safeline-postgresql
chaitin/safeline-redis
```

（版本标签随官方发布变化，请以官方离线包内的镜像清单为准。）

## 通用导出/导入流程

联网机：

```bash
for img in chaitin/safeline-mgt chaitin/safeline-detect chaitin/safeline-nginx; do
  docker pull "$img:latest"
  docker save -o "${img##*/}.tar" "$img:latest"
done
tar czf safeline-images.tar.gz *.tar
```

离线机：

```bash
tar xzf safeline-images.tar.gz
for f in *.tar; do docker load -i "$f"; done
docker images | grep chaitin
```

然后按官方离线安装文档用 `docker compose up -d` 启动编排文件。

## 端口与 DNS

离线环境下无法自动拉取镜像加速配置，请提前把 `/etc/docker/daemon.json` 里的 registry-mirrors 指向内网 registry。
