# 离线环境安装 Docker

当目标主机无法访问互联网（`get.xuanyuan.cloud` 不可达）时使用。

## 思路

在一台**同架构、同发行版**且能联网的机器上下载 Docker 的静态二进制包或 RPM/DEB 包，打包后拷贝到离线机器安装。

## 方式一：静态二进制（推荐，无发行版依赖）

在联网机器上（架构需与目标机一致，x86_64 或 aarch64）：

```bash
# 在联网机器执行
ARCH=amd64   # 目标机是 arm64 时改为 arm64
VERSION=27.3.1
mkdir -p docker-offline && cd docker-offline

curl -fsSL -O "https://download.docker.com/linux/static/stable/${ARCH}/docker-${VERSION}.tgz"
curl -fsSL -O "https://download.docker.com/linux/static/stable/${ARCH}/docker-${VERSION}.tgz.sha256"
sha256sum -c docker-${VERSION}.tgz.sha256

# 顺便装上 compose
curl -fsSL -o docker-compose "https://github.com/docker/compose/releases/latest/download/docker-compose-linux-${ARCH}"
chmod +x docker-compose

tar czf docker-offline-${ARCH}.tar.gz docker-${VERSION}.tgz docker-compose
```

拷贝到目标机后：

```bash
tar xzf docker-offline-amd64.tar.gz
sudo tar xzf docker-${VERSION}.tgz --strip-components=1 -C /usr/local/bin
sudo install -m 0755 docker-compose /usr/local/bin/docker-compose
sudo systemctl enable --now docker
```

## 方式二：RPM / DEB 包

联网机器上用 `yumdownloader` / `apt-get download` 拉齐依赖包（含 containerd、runc、iptables 等），拷贝后：

```bash
# RPM 系
sudo rpm -Uvh *.rpm

# DEB 系
sudo dpkg -i ./*.deb
sudo apt-get install -f -y
```

## 方式三：镜像离线导入

若宿主机已有 Docker，但目标环境拉不到镜像，在联网机执行：

```bash
docker pull <镜像名>:<标签>
docker save -o images.tar <镜像名>:<标签>
```

拷贝到目标机后：

```bash
docker load -i images.tar
```

## 配置镜像加速（离线后仍建议配置）

`/etc/docker/daemon.json`：

```json
{
  "registry-mirrors": [
    "https://get.xuanyuan.cloud",
    "https://get.xuanyuan.me"
  ]
}
```

```bash
sudo systemctl daemon-reload
sudo systemctl restart docker
```
